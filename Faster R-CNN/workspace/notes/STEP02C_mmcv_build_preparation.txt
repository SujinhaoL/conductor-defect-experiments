构建选择
MSVC v142 14.29，Windows SDK 10.0.19041.0，x64。
CUDA Toolkit 12.8.1 / nvcc 12.8.93。
TORCH_CUDA_ARCH_LIST=12.0：明确为本机 RTX 5070 Ti 的 sm_120 编译。
MAX_JOBS=4：限制并行编译任务数；这是编译参数，不是训练 batch。
MMCV_WITH_OPS=1、FORCE_CUDA=1；不安装缺少 CUDA 算子的 mmcv-lite。
DISTUTILS_USE_SDK=1，复用显式选择的 MSVC 环境。
pip wheel --use-pep517 --no-build-isolation --no-deps --no-index。
--no-build-isolation 使构建使用已锁定的本实验 PyTorch 和构建工具，不新建一个缺少正确 PyTorch 的临时构建环境。
先生成 wheel、记录 SHA256，再用 --no-deps 安装该 wheel。
本地源码不做功能补丁，也不向其他环境安装包。

验收内容
pip check，保存安装包完整版本列表。
mmcv=2.1.0、mmengine=0.10.7、mmcv._ext 必须来自本项目 .venv。
扩展记录的编译 CUDA 必须为 12.8 系列；保存编译器信息。
CPU 与 GPU NMS：使用已知框和得分，核对固定预期保留索引与数值。

CPU/GPU RoIAlign：与 torchvision CPU 参考结果比较前向输出和输入梯度。
梯度检查只是一次小型算子测试：没有模型、数据集、优化器或训练迭代。
这些检查覆盖 Faster R-CNN 的关键算子，不宣称测试了 MMCV 的每一个算子。
