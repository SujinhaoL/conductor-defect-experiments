# Faster R-CNN 1280：诊断全流程总览

教师讨论版 · v1 · 2026-10-20 · 阶段性记录

主运行：FRCNN-R50FPN-SCALE1280-VAL-001 / step11_31112_14115；Resize=(2133,1280)，保持长宽比，默认anchor scale=8；原train107 / val23。第5轮是已固定最佳验证权重，第100轮只用于末期拟合诊断。类别：broken（断股）、loose（松股）。

## 1. 希望老师帮助判断什么

本轮按“看预测 → 看模型输入 → 看训练与评价代码 → 必要时看候选框过程”的顺序排查。当前问题是：效果低究竟有哪些可观察原因，是否还存在需要排除的实现问题，以及下一项最小检查该选什么。

本报告不是“全部环节已证明正确”的结论。前三步限定范围检查已完成；第四步先复用历史STEP12材料并说明证据缺口。未因本次整理重跑训练、模型推理或test，未改数据划分、输入尺寸、anchor、权重选择和正式指标。代码学习不作为继续排查的前置条件。

术语速查：train=训练集，val=验证集，test=测试集；epoch=遍历一轮训练集，batch=一批图像；GT=人工标注，IoU=框的交并比；Resize=图像缩放，anchor=预设锚框，loss=损失。mAP50与mAP50–95分别采用IoU=0.50、IoU=0.50到0.95的评价门槛；它们不是简单的检出比例。

## 2. 当前最值得讨论的三项事实

- 显示无框不等于无预测：第5轮val有2300个保存框，但最高分约0.1706，全部低于旧显示阈值0.30。低分框已经参与原AP评价；降低显示阈值只改变画图。
- 低分不是唯一现象：第5轮val的37个GT中，16个有同类IoU≥0.50保存候选，另外21个没有。存在重合候选也不等于一对一正确检测。
- 同一第100轮权重在训练8图和验证23图上的表现差距明显。输入管线与限定范围代码核查尚未发现具体错位/适配冲突，但这不能直接证明低分只由样本少、目标小或某个模块造成。

## 4. 训练与验证结果必须分开解释

|权重 / 评价集合|图 / GT|保存框 / 分数>0.30|有同类IoU≥0.50候选的GT|mAP50|mAP50–95|
|---|---|---|---|---|---|
|第100轮 / 原train固定子集|8 / 15|33 / 11|11 / 15|80.1980%|80.1980%|
|第100轮 / 原val|23 / 37|78 / 8|4 / 37|0.5941%|0.1628%|
|第5轮 / 原val（已固定最佳轮）|23 / 37|2300 / 0|16 / 37|3.1893%|1.4878%|

前两行属于同一权重的拟合/验证对照；训练8图是已参与107图训练的子集，不是全训练集成绩，也不是独立泛化成绩。第5轮单独说明正式验证结果，不与第100轮训练数据冒充同轮对照。此表不含test。

“候选覆盖”逐GT独立找框，没有一对一匹配，不是普通Recall（召回率）、AP（平均精度）或AR100。AP引用已验收历史精确COCO结果。本报告不重新选checkpoint（保存的模型权重）。

## 5. 下一步：先分清两种不同的失败现象

本步科学问题：漏检是否仅仅来自显示分数门槛，还是现有候选的类别或位置已经不够准确？先使用已有保存结果回答，不改参数，不追加训练。以下两图的集合、轮次不同，用于说明现象类型，不能当作相同条件的优劣比较。

### 例A：第5轮 · val · GT177——有重合，但置信度低

![例A：第5轮 · val · GT177——有重合，但置信度低](<D:/小论文/model_projects/Faster R-CNN/workspace/audit/FRCNN-DIAG-SAVED1280-001/diag01_20261019_010031_868401/crops/val23_epoch005_gt177.jpg>)

GT是人工标注；177是标注编号，不是图片编号。绿色为GT，橙色为保存框中同类最大IoU候选。IoU≈0.615529，分数≈0.051652。IoU是两个框交集面积/并集面积，不是置信度。这个框已被保存且参与AP，只在旧0.30显示阈值下被隐藏。

### 例B：第100轮 · train · GT123——现有候选位置重合不足

![例B：第100轮 · train · GT123——现有候选位置重合不足](<D:/小论文/model_projects/Faster R-CNN/workspace/runs/FRCNN-DIAG-RPNROI-TRAIN8/step12_24867_6686/scale1280/gt_123.jpg>)

绿色GT；蓝色为交接RPN候选中最大IoU框；红色为最终同类最大IoU框。图中NO_RPN_IOU50表示交接候选中没有IoU≥0.50框；RPN IoU 0.353和final IoU 0.342分别是两个集合的最大值，不表示同一个框回归后变坏。ROI同类过滤前最大IoU约0.3661，仍低于0.50；仅降低显示阈值不能修复这个位置差距。

- RPN（Region Proposal Network，候选区域生成网络）：先提出可能包含目标的位置。已保存的交接候选经过RPN自身NMS（重叠候选去重）及最多1000框筛选，不是原始全量候选。
- ROI（Region of Interest，候选区域）阶段：对候选区域进一步分类并调整框位置。它训练时还会加入GT候选，因此RPN正anchor不足不等于整个模型从未学习该目标。
- 现有1280末轮训练8图共有15个GT：RPN、ROI同类过滤前、最终同类框均覆盖11个；剩余GT87、123、124、160均为loose。这定位了这4个训练目标的候选覆盖不足，但未定位RPN生成、排序、去重各自的贡献。
- 本阶段停止条件：能够区分低分与定位不足，并把不能解释的部分明确列出。不会为了凑齐所有内部张量而无限扩展诊断。若需要解释最佳第5轮val的21个未覆盖GT，应先利用DIAG01已保存结果分类错误；只有保存结果确实无法区分具体环节时，才准备少量train/val的新推理，由用户启动。

## 6. 尚待验证的原因与已有反证

- 小目标尺度、细长外观、缺陷与正常导线相似、样本覆盖不足或标注边界差异，都仍是候选解释；目前没有证据把其中任何一个认定为全部低分的唯一原因。
- 默认anchor几何限制与上述4个训练漏检相吻合，支持一个局部假设。历史anchor4对照已完成：训练8图拟合改善，但主要val mAP50–95由1.4878%降至1.1591%。因此不能把改善训练拟合等同于解决验证问题，也无需重复已有anchor对照。
- 原始RPN过滤前全部候选、第5轮val完整RPN/ROI中间输出、历史训练随机采样/逐层梯度并未全面保存。现有导出不满足“原始所有框全部恢复”的强表述；不是所有缺失都必须补做。
- scene_id未知且为空；已登记split_group_id未跨集合，不等于所有同源图像已彻底排除。原test在项目历史中已多次评价且分数被查看；本次诊断只用train/val，没有重新读取test预测或追加test。单seed、小验证集、多轮开发的限制仍须披露。

## 7. 希望老师给出的具体指示

- 标注规范：松股/断股框应覆盖哪一段可见缺陷？GT123等紧小框是否符合统一标准？请结合原图判断，不因模型框较大就修改标注。
- 排查是否还缺关键证据：前三步及已有训练候选诊断是否足以进入针对性方法分析？如需补查，优先指定最佳第5轮val中的少量失败例，明确要区分哪两个原因。
- 研究方向：在不立即扩充数据的前提下，下一项最小对照应针对输入后目标细节、候选匹配，还是训练/验证分布差异？当前不预先承诺哪项必然有效。

## 8. 文件、状态与使用方式

这份总览作为持续更新的主记录；每完成一个诊断阶段再更新，保留Git历史与阶段性快照。本版本记录到2026-10-20，不能当作未来所有步骤已完成。原始报告、日志、模型权重和指标文件不被覆盖。

给老师阅读：优先发送同内容的单文件HTML；两张代表图已经嵌入，无需另带图片目录，离线浏览器可打开。也可浏览器打印为PDF。来源路径是本机证据索引，换一台电脑不会自动拥有这些原始文件。HTML的图片和文字已保留，复制HTML即可阅读主体。

代码学习是可选项。助手负责技术核查；用户负责需要实际运行时启动cmd并反馈，以及对缺陷语义/可视化提出观察。当前没有必须运行的训练或推理命令，也没有必须提交的学习作业。

若老师还需要九次正式实验的val/test成绩，另附已有“模型实验简表_教师讨论版.xlsx”。它是成绩表，本报告是诊断过程；本次未修改成绩表。
