安装资料初查与待核实事项
RTX 5070 Ti 属于 compute capability 12.0 的 Blackwell GPU。
PyTorch 官方说明 2.7 引入 Blackwell 支持和 CUDA 12.8 wheel。
MMDetection 3.3.0 官方兼容表：MMCV >=2.0.0,<2.2.0；MMEngine >=0.7.1,<1.0.0。
v3.3.0 源码 assert 的 MMCV 下界为 2.0.0rc4，上界同为严格小于 2.2.0；正式环境应使用稳定版。
MMCV 官方说明预编译包依赖 PyTorch/CUDA/平台组合，找不到对应包时需从源码编译。
这些资料不能证明 Windows + sm_120 + 某一 PyTorch/MMCV 组合已能运行。
当前尚未冻结 Python、PyTorch、MMCV、MMEngine 版本或代码 commit；未确认目标 wheel 的可用性。
不要直接复制旧版 torch/cu118/mmcv 安装组合，也不要通过改 assert 绕过版本检查。
下一步先核对用户 VS Code cmd 输出，再确定独立环境和可验证的安装路线。
之后必须逐步通过 CUDA、MMCV CUDA 算子及官方 COCO 示例推理，才能准备小样本训练。
