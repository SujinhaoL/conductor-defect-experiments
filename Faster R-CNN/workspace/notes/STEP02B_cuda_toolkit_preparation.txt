本阶段目的
PyTorch 的 cu128 wheel 已包含其运行所需的 CUDA 库，但不等于安装了完整的 CUDA C++ 编译工具。
为后续从官方源码构建 MMCV 扩展，补齐 CUDA Toolkit 的编译器、头文件、开发库。
固定 CUDA Toolkit 12.8 Update 1（12.8.1）；其 nvcc 组件版本为 12.8.93（已按官方组件清单及本机文件纠正）。
版本与现有 torch 2.7.1+cu128 的 CUDA 主次版本一致。
本次通过不等于 MMCV 已可用；MMCV 构建及算子验收仍是后续独立阶段。
不运行任何模型训练，不安装 MMCV，不转换数据，不操作其他模型的 Python 环境。

Windows NVCC 压缩包名称也包含 12.8.93。本机 version.json 和 nvcc --version 均为 12.8.93。
因此采用相互一致的官方组件清单、安装后的组件元数据及可执行程序实际版本作为验收依据。
12.8 Update 1 对应 Windows 驱动要求 >=572.61；已有 591.86 满足，不安装包内驱动。
本地 Windows 构建号比归档文档逐项列出的 Windows 11 版本新，因此以实际编译运行验收为准，不宣称整套组合已获官方逐项认证。
