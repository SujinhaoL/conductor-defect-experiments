# 输电导线缺陷 bbox 尺寸统计

本文件仅对现有 YOLO 格式 GT 标签进行只读计算。没有训练模型，也没有运行 val/test。

## 1. 统计范围与预处理定义

- 数据集：`D:\小论文\conductor_defect_dataset\02_yolo11_dataset`
- GT bbox 总数：241（broken=56，loose=185）
- YOLO 基础尺寸参考：按源码将图像长边等比例缩放到 imgsz，使用 `ceil` 后居中 letterbox；bbox 按实际横纵缩放比换算。
- RT-DETR 基础尺寸参考：`RTDETRDataset.load_image(..., rect_mode=False)` 将图像直接 resize 到 imgsz×imgsz；bbox 横纵方向分别缩放。
- 训练期说明：两个正式实验均保留官方随机 Mosaic/几何增强。随机增强会改变单个 batch 中的目标尺寸，因此下表是单图基础预处理参考，不是每个随机训练样本的唯一尺寸。

源码依据：

- `D:\小论文\model_projects\yolo11\ultralytics_src\ultralytics\data\base.py`：`load_image` 的等比例长边缩放与 `rect_mode=False` 方形拉伸。
- `D:\小论文\model_projects\yolo11\ultralytics_src\ultralytics\data\dataset.py`：YOLODataset 的训练/验证 transforms。
- `D:\小论文\model_projects\yolo11\ultralytics_src\ultralytics\models\rtdetr\val.py`：RTDETRDataset 默认 `rect_mode=False`。
- `D:\小论文\model_projects\yolo11\ultralytics_src\ultralytics\data\augment.py`：LetterBox 和 v8_transforms。

## 7. 对 1280 与 1600 的回答

1. **1280 后目标有多小：**YOLO 基础 letterbox 参考的 short-side median 为 12.74px；RT-DETR 方形拉伸参考为 17.58px。
2. **类别差异：**YOLO@1280 下 broken median=18.14px，loose median=11.74px；RT-DETR@1280 下分别为 22.76px 和 15.81px。
3. **低于阈值比例：**YOLO@1280 short<8/16/32px 分别为 25.31%/63.49%/87.97%；RT-DETR@1280 分别为 13.69%/44.40%/83.40%。
4. **提高到 1600：**YOLO median 从 12.74px 增至 15.92px（25.0%）；short<16px 从 63.49% 降至 50.21%。RT-DETR median 从 17.58px 增至 21.98px（25.0%）；short<16px 从 44.40% 降至 35.27%。
5. **是否值得做分辨率敏感性实验：**从 bbox 像素尺寸角度，有进行一次受控 1280→1600 敏感性实验的价值，因为 1600 能确定性增加输入空间中的 bbox 像素尺寸，并使部分目标跨过 8/16/32px 阈值。但该统计不能预测 mAP 必然提升；显存、batch、公平对照和随机增强都需要另行控制。

## 8. 解释边界

- 这些统计证明的是标注框在不同基础预处理下的像素尺度，不证明模型失败由缩放这一单一因素造成。
- 方形拉伸会使横纵尺度分别变化，可能改变 bbox 形状；本文件只忠实模拟源码行为，不评价其优劣。
- Mosaic、RandomPerspective、scale/translate 等随机增强会继续改变训练样本中的目标尺度和可见区域。
- 更高 imgsz 具有尺寸层面的实验价值，但不等于精度保证。
